# Owner preferences — MoneyWise / okaneyan.

**Last consolidated:** 2026-10-29. Preferences below are traceable to direct user statements, supplied image/brief, or established decision documents. A candidate is not a final selection.

## Confirmed

- Native iOS / SwiftUI is the product; browser output is only a responsive preview/review surface.
- Retain the dark expressive base unless the owner explicitly approves a change.
- Okaneyan identity: charcoal/black, soft white, muted pastel rose; matte material; restrained rose highlight; no arbitrary purple/indigo or decorative glow.
- Distinctive editorial/brutalist restraint, meaningful composition, typographic personality, readable Russian and a product feel that does not look like generic AI fintech.
- User likes CoFo Drifter, CoFo Glassier and CoFo Kak as type references; files and app embedding rights are not available/verified.
- User-provided brand image `вв.png` shows `okaneyan.` identity and mark concept: balance + flow + point. Its pink/graphite mark on dark matte context is the reference.
- Keep functions Living Card + Spending Lock, Financial Horizon + Time Machine, Financial Gravity.
- Spending Lock is a local planning reserve, not a real bank lock.
- Oswald is a promising typography candidate only; it has not been selected as the production font.
- Current product screen is Overview and should answer: “How much is truly available to spend, until when, and why?”
- Existing direction D1/A “Тихий горизонт” remains the current approved base (DEC-008); do not silently replace it.
- Financial data must be truthful: no invented balance; distinguish manual/current, confirmed, expected and planned values.
- Avoid template AI dashboards, endless equal cards, random gradients, decorative glow, icon in every heading, artificial futurism, and banking/crypto claims not implemented.

## Historical feedback that remains a guardrail

- The user said an earlier card-focused web version “was very cool”; preserve the card/horizon motif and recognizable rhythm while improving the current Overview.
- The user rejected a later palette/layout as “colors not right” and called iterations AI-ish; avoid unexplained palette drift and generic dashboard composition.
