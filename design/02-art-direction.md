# G1 — три направления для flagship «Обзор»

**Статус:** `APPROVED — SOFT MATTE FINTECH` по дополнительному MASTER-ТЗ пользователя от 2026-10-29. Вариант A «Тихий горизонт» остаётся выбранной рекомендованной композицией для flagship; B/C сохранены только как переключаемые сравнения web review-preview, не как production-настройка.

## Сравниваемый экран

Обзор iPhone: приветствие/дата, одна главная сумма «Свободно до поступления», причина расчёта, ближайшие обязательства, последние операции, действия «Проверить покупку» и «Добавить операцию». При неизвестном балансе/устаревших данных сумма не заменяется выдуманной цифрой — показывается правильное состояние «Недостаточно данных» и следующий полезный шаг.

## Компактные токены-кандидаты

- Чернильный чёрный `#191516`; мягкий фон `#F5F1F2`; белая поверхность `#FFFCFD`; приглушённая роза `#D9AEB8`; глубокая роза `#805D66`; граница `#E8DFE2`.
- Тёмная тема: фон `#141213`, поверхность `#201C1D`, raised `#2A2426`, основной текст `#F6F0F1`, вторичный `#B6AAAD`, розовый акцент `#D9AEB8`; смысловые success/warning/danger — отдельные спокойные цвета, розовый не кодирует риск.
- Заголовки: системная кириллическая sans до наличия лицензированных CoFo; Glassier — только исследуемый display-кандидат; Drifter — сумма/короткие data labels после glyph QA; Kak — короткий брендовый акцент, не цифры и не плотные списки.
- Layout: нативная вертикальная прокрутка, safe areas iPhone, крупные hit areas; web-preview — только для проверки композиции в 390/768/1440 px.

## A — «Тихий горизонт» (основная композиция в выбранном Soft Matte Fintech)

Чернильный canvas в тёмной теме и тёплый chalk canvas в светлой; широкая matte-карточка доступных средств с неяркой розовой временной дугой, которая становится мини-осью «сейчас → обязательство → доход». Сразу под ней — 2 короткие суммы «резерв»/«обязательства», далее крупные строки операций.

```text
┌ Обзор                         ◉ ┐
│  ДО СЛЕДУЮЩЕГО ПОСТУПЛЕНИЯ     │
│  42 500 ₽                 ↗    │
│  4 дня · 1 ноября              │
│  ──●────────●────────○──        │  ← дата аренды → поступление
│  Резерв 180 000   Платежи 33 250│
└───────────────────────────────┘
  [ Проверить покупку ]  [ + ]
  Ближайшее
  Аренда · 1 ноября          32 000 ₽
  Недавние операции …
```

Плюсы: сумма и объяснение плана считываются за один взгляд; signature принадлежит именно продукту. Риск: графика может выглядеть как гарантированный прогноз — показывать только фактический/подтверждённый timeline, неопределённость маркировать текстом.

## B — «Счётная книга»

Светлый фон бумаги, тёмная ink-типографика, строгие тонкие разделители, числовые акценты CoFo Drifter после glyph QA. Свободная сумма спокойнее, главный сюжет — упорядоченный список дат, входящих и обязательств. Тёмная тема инвертирует поверхности, не становится терминалом.

```text
┌ Деньги · пятница               ┐
│ Свободно до поступления        │
│ 42 500 ₽                       │
├────────────────────────────────┤
│ 01 ноя · аренда       −32 000 ₽ │
│ 05 ноя · связь        −1 250 ₽ │
│ 10 ноя · Япония        −8 000 ₽│
├ резерв 180 000 · данных 31 окт ┤
│ Проверить покупку       →       │
└────────────────────────────────┘
```

Плюсы: высокое доверие, удобство плотной истории. Риск: может стать слишком похожим на банковскую выписку и ослабить личный голос продукта.

## C — «Мягкая поверхность»

Мягкий белый/графит, карточки двух матовых высот, розовый только как материал/тонкая метка; крупные короткие заголовки на базе доступной кириллической гарнитуры. Визуальный фокус — раскрывающаяся карточка плана с деталями расчёта.

```text
┌ Свободно                         ┐
│ 42 500 ₽     до 1 ноября         │
│ [разобрать сумму  ↓]             │
└──────────────────────────────────┘
┌ Что уже учтено                   ┐
│ Резерв       180 000 ₽       ··· │
│ Обязательства 33 250 ₽      ··· │
└──────────────────────────────────┘
┌ Последние операции            → ┐
```

Плюсы: естественные карточные переходы и хорошая доступность деталей. Риск: близко к привычному fintech-шаблону и предыдущему ощущению «слишком просто»; нужна очень сильная композиционная дисциплина.

## Критика и выбор

Сравнивая направления на один и тот же экран, A лучше связывает реальную задачу пользователя — «сколько безопасно до поступления и почему» — с собственным запоминающимся элементом. Его принимаем как **рекомендуемую гипотезу для flagship**, не как утверждённый G1: перед широким UI rollout сравнение должно быть принято. Берём из B точность типографики и из C раскрываемую детализацию; не превращаем всё приложение в хронологическую таблицу или набор пухлых карточек.

| Роль | Light | Dark |
|---|---|---|
| Canvas | `#F5F1F2` | `#141213` |
| Surface | `#FFFCFD` | `#201C1D` |
| Surface raised | `#F0E9EB` | `#2A2426` |
| Ink | `#191516` | `#F6F0F1` |
| Muted | `#766D70` | `#B6AAAD` |
| Accent | `#A77B85` | `#D9AEB8` |
| Focus | `#79535D` | `#EDC4CE` |

Цвета-индикаторы «можно/риск/недостаточно» определяются семантикой результата `MoneyCore`, имеют отдельную подпись и не кодируются только цветом.


## Зафиксированное направление после дополнительного ТЗ

Soft Matte Fintech — утверждённая эстетика для дальнейшей разработки. Композиция A используется как текущая основная. В web preview selector A/B/C помогает сравнить направления и не предназначен для будущего production-интерфейса. Финальный runtime rollout относится к SwiftUI; web screenshots являются только референсом для review.
