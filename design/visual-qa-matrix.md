## Не закрыто

- Светлая тема снята на D1/D2/D3 Overview для 390/1440; остальные разделы не имеют полной light/dark матрицы.
- Нет нативных снимков пустых/error состояний и проверки системного Dynamic Type. Web text-only stress 150/200% выявил clipping/пересечение при 200%; кадры и метод записаны в `design/research/visual-gap-audit.md`. Длинное денежное значение проходит в базовом размере, длинные локализованные строки остаются не проверены.
- Отрицательный 7-дневный сценарий снят для всех трёх направлений; другие отрицательные/предельные значения и длительности ещё не проверены визуально.
- Не проверены физический iPhone, Safari, VoiceOver, Dynamic Type, системный Reduce Motion, производительность и FPS.
- Empty state доступен в web-preview как явный QA route, чтобы проверить его вид; он не подменяет настоящий data-driven пустой запрос. В iOS проверка ограничена существующим SwiftUI `ContentUnavailableView` и не проходила runtime/скриншот на устройстве.
- Владелец выбрал Soft Matte Fintech / A «Тихий горизонт» (DEC-008); D1 остаётся default preview representation, D2/D3 — сравнительными вариантами. Независимой дизайнерской критики нет.
- D1/D2/D3 различаются структурой и иерархией, но их независимая сравнительная оценка ещё не проведена. Направление не требуется выбирать повторно.
- Ролики теперь покрывают feedback, navigation, state и signature в web-preview, включая reduced-motion пары для feedback/navigation/signature и reduced-motion disclosure. Не проверены физический iPhone, Safari, VoiceOver, Dynamic Type, системный Reduce Motion, производительность и FPS.
