# Mobile QA summary

Current web preview: responsive Chromium/Playwright evidence recorded in `10-mobile-ux-audit.md`, `11-touch-target-audit.md`, `12-usability-test-matrix.md`, and `13-mobile-qa-report.md`.

**Passed in browser emulation:** required viewport widths, portrait/landscape reflow, 44 px targets, no intersecting interactive targets, tabs, animated balance disclosure, theme, amount masking, demo add flow, keyboard dialog focus and reduced motion. Expanded balance disclosure has also been checked at 320/360/390/430/768/1024/1440 and two phone-landscape viewports.

**Not verified:** physical iPhone/Android, Safari/Chrome mobile, Home Indicator/Dynamic Island safe areas, real software keyboard, one-handed user behavior, 200% zoom, VoiceOver/TalkBack and actual gesture accuracy. User testing is `NOT_CONDUCTED`.
