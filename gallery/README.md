# Галерея изображений MoneyWise / okaneyan.

Локальная галерея существующих изображений основного проекта и его доступных worktree: референсы, нативные экраны, веб-макеты и брендинг. Точные копии объединены по содержимому, все исходные расположения перечислены в просмотре. Присутствие референса не означает его утверждение.

Запуск: `python3 gallery/serve.py`, затем http://localhost:5176/. Сервер доступен только на этом компьютере и раздаёт только папку галереи. Повторный запуск обновляет каталог. После первого построения можно открыть `gallery/index.html` напрямую без сервера: каталог, копии изображений, миниатюры и ранее утверждённые шрифты находятся локально. Исходные изображения не изменяются. Новые библиотеки и сетевые ресурсы не требуются.

Работают поиск по имени/папке/тегам, группы, фильтр формата, сортировка, полноразмерный просмотр, масштаб 1:1, смена фона, клавиши ←/→ и Escape. Сортировка по дате означает дату изменения локального файла, а не дату публикации референса.
