# Visual DNA — рабочая карта применения

Актуальное основание: [контракт пользователя](../CREATIVE_IMPLEMENTATION_CONTRACT.md). Новое разрешение развивать материальность Living Card заменяет прежние запреты на 3D-текстуру в исторических предложениях. Исследовано ≠ одобрено. Неустановленные свойства не восстановлены по названию.

## Очерёдность и ещё не подтверждённое

Living Card → Financial Horizon → Time Machine → Spending Lock → Financial Gravity → навигация. Эта матрица не означает, что художественная приёмка всех компонентов завершена. Для референсов с недостающими первичными изображениями остаётся восстановление оригиналов; для выбранной карточки — render/contrast/Reduce Motion/gesture evidence. Авторских ассетов и внешних шрифтов не добавлено.
