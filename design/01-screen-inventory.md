# Инвентаризация экранов и состояний

**Область:** `preview/index.html`, интерактивный web review-прототип; не заменяет нативный SwiftUI аудит.

| Раздел / состояние | Содержание и действия | Границы / непроверенное |
|---|---|---|
| Обзор | Ручной остаток, резерв, денежный горизонт, предстоящие платежи, недавние операции, лимиты и цель. Переключатель концепта, light/dark, скрытие сумм, раскрытие горизонта. | Статичные синтетические данные; нет банковской загрузки или динамических ошибок. |
| Операции | Демо-список, категория расходов, переход к добавлению. | Фиксированный список; фильтры только показывают поясняющий toast. |
| План | Обязательства, цели/лимиты, проверка покупки, добавление в план. | Проверка покупки использует демонстрационный остаток; не финансовый расчёт `MoneyCore`. |
| Диалог добавления | Поля названия и суммы; локальная вставка строки в список; toast. | Сохраняется только в текущем DOM, исчезает после reload. |
| Диалог добавления в план | Общая форма, demo-обратная связь. | Нет модели расписания/персистентного плана в web preview. |
| Диалог проверки покупки | Сумма и демонстрационный результат. | Не использует нативный purchase verdict. |
| Dialog states | Open, keyboard focus, invalid form, close by button / Escape / backdrop, successful add. | Server/network/loading/error/empty state отсутствуют по природе локальной демонстрации. |
| Theme / privacy | Переключение светлой/тёмной темы; маскировка `.amount` в DOM. | Состояние не сохраняется при reload; это не обещание приватности системных снимков. |

## Инвентаризация платформ

- Shipping product: iOS SwiftUI, исходники `iOSApp/` и `Sources/`; проверка отдельно ограничена отсутствием Xcode/iOS Simulator в текущей среде.
- Review target: статический адаптивный preview на `http://localhost:5175/`; проверки ниже доказывают только браузерную версию.
- Реальные платежи, bank API, account auth, графики с интерактивными tooltips и bottom sheets в preview отсутствуют.
